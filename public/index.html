Дані та методика ↓

Браузер завантажує відкритий протокол АРМА через Cloudflare Worker і локально рахує голоси та будує графіки. Автооновлення — через 5 хвилин після кожного завантаження; вручну — не частіше ніж раз на хвилину. Якщо Worker недоступний, сайт використовує останню копію GitHub Pages.

Один запис містить до 9 вибраних кандидатів. Час записів інтерпретується як час Києва. IP-адреси й хеші не відображаються. Показники попередні; офіційні результати оголошує АРМА. Сайт не пов’язаний з АРМА.
