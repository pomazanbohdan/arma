# Підсумковий dashboard голосування до РГК при АРМА

Сайт: [pomazanbohdan.github.io/arma](https://pomazanbohdan.github.io/arma/). Він показує підсумковий зріз протоколу для 27 кандидатів, динаміку записів та список голосів. У динаміці спочатку показані всі лінії; періоди й режим підрахунку можна змінити. Кандидати №3, 5, 8, 13, 19, 23, 25, 27 виділені для порівняння. Графіки використовують Apache ECharts із CDN.

## Зафіксовані дані

`public/data/hashed_report.txt` — остаточна копія протоколу з останнього опублікованого GitHub Pages артефакту `github-pages`, run `36998735619`. Артефакт створено 2 жовтня 2026 о 11:01:54 UTC (14:01:54 за Києвом), після завершення голосування. Він містить 8 891 запис; останній запис має час 2 жовтня 2026, 09:04:28.109 за Києвом.

SHA-256 файла: `e7777cd3847c0e5cf19ee3520462a74823907984ccedfddc51552fd4618d9e4a`. Хеш скопійованого файла збігся з метаданими артефакту та відкритим протоколом АРМА на час фіналізації. `public/data/meta.json` містить час копії, кількість записів, хеш та адресу джерела. Браузер завантажує лише ці локальні файли сайту й рахує показники; запитів до proxy, живого протоколу чи автооновлення немає.

## Публікація

`.github/workflows/pages.yml` залишено як конфігурацію розгортання GitHub Pages для ручного запуску або push у `main`; розклад збору даних видалено. Після фінальної публікації GitHub Actions вимкнено на рівні репозиторію. Поточна версія Pages залишається доступною; нові деплої не виконуватимуться, доки Actions не буде ввімкнено знову.

## Розробка

Потрібен Node.js 22+ і локальний HTTP-сервер.

```powershell
node --test tests/report.test.mjs
python -m http.server 8765 --directory public
```

Відкрийте `http://localhost:8765/`. Підсумковий протокол та метадані входять до Git у `public/data/`.
